# ❌⭕ Tic Tac Toe

A simple and interactive Tic Tac Toe game built with **React.js**. Play as Player X and Player O, detect winners automatically, and restart the game anytime.

## 🌐 Live Demo

🚀 https://tic-tac-toe-falcons18.vercel.app/

---

## ✨ Features

- 🎮 Two-player gameplay
- ❌ Player X vs ⭕ Player O
- 🏆 Automatic winner detection
- 🤝 Detects draw games
- 🔄 Restart game button
- ⚡ Fast and responsive interface
- 📱 Works on desktop and mobile

---

## 🛠️ Built With

- React.js
- JavaScript (ES6)
- HTML5
- CSS3

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/arman184507/TicTacToe.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Open in your browser:

```text
http://localhost:3000
```

## 🎯 Game Rules

- Player **X** always plays first.
- Players take turns placing their marks.
- The first player to get **three marks in a row** (horizontal, vertical, or diagonal) wins.
- If all 9 squares are filled and no player wins, the game ends in a **draw**.
